# 🌍 Travel Dashboard

Интерактивная панель для путешествий с информацией о городах, погоде и достопримечательностях.

## ✨ Основные функции

### 🏙️ Информация о городах
- Поиск городов по названию
- Автоматическое определение местоположения по IP
- Детальная информация о городе
- Фотографии городов

### 🌤️ Погода и время
- Текущая погода в выбранном городе
- Местное время
- Прогноз погоды
- Перевод погодных условий на 4 языка

### 🏛️ Достопримечательности
- Поиск достопримечательностей в радиусе
- Детальная информация о местах
- Фотографии достопримечательностей
- Фильтрация по типам мест

### 🗺️ Интерактивная карта
- Отображение достопримечательностей на карте
- Разные маркеры для достопримечательностей и рекомендаций
- Попапы с информацией о местах
- Адаптивная карта для всех устройств

### 🌍 Многоязычность
- Поддержка 4 языков: Русский, English, O'zbekcha, 中文
- Автоматическое определение языка
- Сохранение выбранного языка
- Полный перевод интерфейса

### 🌙 Темная тема
- Переключение между светлой и темной темой
- Автоматическое определение системной темы
- Сохранение выбора темы
- Плавные переходы между темами

### 🔔 Система уведомлений
- Уведомления о достижениях
- Информационные уведомления
- Автоматическое исчезновение
- Адаптивный дизайн

### 🏆 Система достижений
- 8 различных достижений
- Система очков
- Уведомления о новых достижениях
- Сохранение прогресса

### 📱 PWA (Progressive Web App)
- Установка как нативное приложение
- Офлайн режим
- Service Worker для кэширования
- Манифест приложения

### 👤 Система профилей
- Персональный профиль для каждого пользователя
- Любимые города и достопримечательности
- Статистика использования приложения
- История посещенных городов
- Достижения и очки
- Настройки пользователя

## 🚀 Технологии

- **React 19** - Основной фреймворк
- **Vite** - Сборщик проекта
- **React Router** - Маршрутизация
- **i18next** - Интернационализация
- **Leaflet** - Интерактивные карты
- **React Icons** - Иконки
- **CSS Variables** - Темы


### Система уведомлений
- Уведомления появляются в правом верхнем углу
- Автоматическое исчезновение через 5 секунд
- Возможность закрыть вручную

### Достижения
- **Первый город** - Посетили первый город
- **Полиглот** - Сменили язык приложения
- **Ночной режим** - Включили темную тему

- **Наблюдатель погоды** - Проверили погоду в городе
- **Охотник за достопримечательностями** - Просмотрели достопримечательности
- **Мастер рекомендаций** - Изучили рекомендации
- **Глобальный путешественник** - Посетили 3 или более городов

### PWA функции
- Установка как приложение
- Офлайн режим
- Кэширование данных
- Адаптивный дизайн

### Система профилей
- **Персональный профиль** - данные сохраняются локально
- **Любимые города** - добавление городов в избранное
- **Любимые достопримечательности** - избранные места

### 💰 Конвертер валют
- **Реальное время** - актуальные курсы валют
- **Популярные валюты** - 12 основных валют мира
- **Быстрые конвертации** - популярные пары валют
- **Детальная информация** - курс обмена и время обновления
- **Адаптивный дизайн** - работает на всех устройствах

### 📅 Календарь путешествий
- **Планирование поездок** - добавление новых поездок с датами
- **Типы поездок** - отдых, бизнес, семейная, приключение
- **Статусы** - запланировано, в процессе, завершено, отменено
- **Статистика** - количество поездок по статусам
- **Интеграция с профилем** - доступен в разделе профиля
- **Валидация дат** - нельзя выбирать будущие даты

### ⭐ Избранные города
- **Быстрый переход** - переход на главную страницу с выбранным городом
- **Управление избранным** - добавление и удаление городов из избранного
- **Интеграция с профилем** - доступно в разделе "Избранное" профиля
- **Статистика** - количество посещений, время использования
- **Достижения** - система очков и достижений
- **История** - все посещенные города с датами
